# GRE
Official PyTorch Code of "Generative reconstruction of high-resolution historical climate fields from station observations"

## diffusion_github.py
Self-contained training script for a v-prediction diffusion model that generates daily CMFD v2.0 atmospheric fields over research area (15–35°N, 90–110°E, 0.1° resolution, 200×200 grid). The model operates on four normalized variables (prec, pres, wind, temp) conditioned on static fields (day-of-year solar altitude and normalized elevation) and learns the v-parameterization v = α·ε − σ·x on CMFD daily samples spanning 1981–2020. The architecture is a time-conditioned residual U-Net (UNet_1degV1) with sinusoidal time embeddings, GroupNorm + SiLU residual blocks, max-pool downsampling, bilinear upsampling, and skip connections. All diffusion utilities and model components are inlined. Training is launched with accelerate; checkpoints (<name>_<ts>_<loss>.pt and _<ts>_best_<loss>.pt) are written to /data/model/ with a top-20 retention policy and resumed automatically from the most recent file.

## unet_forecast_github.py
Self-contained training script for a deterministic U-Net next-day forecaster F_ξ : R^{4×H×W} → R^{4×H×W} over the same domain. The model is a multi-scale encoder–decoder U-Net (ForecastUNet) with two-conv residual blocks (3×3 conv + GroupNorm + SiLU + residual), max-pool downsampling in the encoder and bilinear upsampling in the decoder, and skip connections between matching stages. It predicts the next day's four-variable field from the current day's field. Training pairs (x_t, x_{t+Δt}) are consecutive CMFD v2.0 daily samples; the period 1981–2015 is used for training and 2016–2020 is held out as an independent validation set. The loss is plain mean squared error L = 𝔼_t ‖F_ξ(x_t) − x_{t+Δt}‖². The best model (forecast_unet_best.pt) and the most recent periodic snapshots are written to /data/model/, with automatic resume from the latest checkpoint.

Both scripts depend only on torch, numpy, netCDF4, tqdm, accelerate (diffusion script only), and einops (diffusion script only); all tunable hyperparameters (paths, channels, learning rate, batch size, epochs, checkpointing policy) are declared in a single Config block at the top of each file.
